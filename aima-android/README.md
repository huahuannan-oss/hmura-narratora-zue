# AIMA CYBER SYNTETYC na Android

Oddzielny projekt Android, bez animacji. Głowa jest identyczna z oryginalnym obrazem przesłanym przez użytkownika. Żaden klucz API nie jest zapisany w repozytorium. GitHub Actions tworzy instalacyjny APK debugowy i udostępnia go jako artefakt `AIMA-CYBER-SYNTETYC-APK`.

Projekt nie zmienia głównej gałęzi chmury narratora. Do rozmowy potrzebny jest własny klucz Google Gemini API.
