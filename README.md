# CHMURA NARRATORA ZUE

Prywatne studio wideobooków. Wgrywasz cały PDF w przeglądarce, a aplikacja renderuje strony, odczytuje krótki wstęp, pokazuje spis treści bez głosu, czyta od rozdziału I i umożliwia pobranie MP4 i MP3. Brak sklepu i płatności.

Uruchomienie: Dockerfile (Render Web Service, plan free). W Render ustaw CHMURA_PASSWORD oraz CHMURA_SESSION_SECRET jako tajne zmienne środowiskowe.

Uwaga: darmowy Render ma ograniczoną pamięć RAM/CPU, zasypia bez aktywności i nie zapewnia trwałego przechowywania plików. Długie wideobooki (np. 250 stron) mogą przekraczać możliwości planu Free. Po ukończeniu pobierz MP4 i MP3 na komputer. Synteza Edge TTS wymaga internetu i zależy od dostępności usługi. Sprawdź zasady użycia głosu przed komercyjną dystrybucją nagrań.
